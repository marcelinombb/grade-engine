Grade Engine

Validador de fórmulas de cálculo de notas

Digite uma fórmula para conferir se ela é sintaticamente válida antes de cadastrá-la. A validação roda inteiramente no navegador, usando a mesma gramática do motor de cálculo Java (lexer + parser).

Comece a digitar para validar.

Exemplos

Referência da gramática

Números
7, 7.5
Variáveis
qualquer identificador alfanumérico, ex: P1, nota_final
Aritmética
+   −   × (*)   ÷ (/)
Comparação
>   <   >=   <=   = (igual)   ! (diferente)
media(...)
média aritmética, mínimo 1 argumento
min(...) / max(...)
mínimo 1 argumento
if(cond, a, b)
o primeiro argumento precisa ser uma comparação
Parênteses
agrupam sub-expressões, até 200 níveis de aninhamento
Validação local, fiel à gramática de com.gradeengine.domain.Parser — nenhuma fórmula sai do navegador.
